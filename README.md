# TorchlightSkill · 火炬工具箱

公开静态官网：[https://torchlightskill.com/](https://torchlightskill.com/)。仓库包含工具介绍页面与公开运行资源。

## 发布目录

GitHub Pages 从 `main` 分支的仓库根目录发布，根目录 `.nojekyll` 保持静态文件直出。

- `index.html`：工具箱首页。
- `talos/index.html`：塔罗斯经营模拟入口，对应 [https://torchlightskill.com/talos/](https://torchlightskill.com/talos/)。
- 根目录 `CNAME`：官网域名；`talos/` 子目录与首页共用域名和 HTTPS。

## 首页背景动效

首页使用炭黑细颗粒材质与灰白强调色。`ambient.js` 持续绘制缓慢折叠、扩散的灰黑流体，鼠标静止时仍有可见的明暗流动；鼠标划过时叠加淡灰墨迹，沿移动方向扩散并在1.8秒内淡出。不绘制跟随圆环或点击涟漪。纹理来自本地 `assets/grain.svg`，动效不加载外部库，所有装饰层均不接收点击，保留系统鼠标指针。

无法使用 WebGL 时显示 CSS 渐变背景；触屏不显示鼠标装饰。系统开启“减少动态效果”时保留静态背景。修改动效或样式后，同步更新 `index.html` 中对应资源的版本参数。

“了解导师”弹窗提供抖音圆形码和主页跳转，按钮文案为“去抖音查看详情和预约内测资格”。二维码使用账号提供的原图，在页面中裁切显示主圆与右上抖音标志，保留原始码点；主页链接为账号提供的 `https://v.douyin.com/okD24Xnc6wo/`。小屏弹窗允许纵向滚动。

## 塔罗斯经营模拟

游戏纯前端运行，图片、声音和 Three.js 随静态文件加载。经营存档与偏好保存在用户浏览器，可通过游戏内导出、导入保留或迁移。

复刻练习与原创挑战，规则持续校准。原创挑战的合约、战斗、压力和积分为实验设定，不代表正式游戏掉落或货币收益；实际玩法以游戏内规则为准。

Three.js 许可证随运行文件保留在 [`talos/vendor/three/LICENSE`](talos/vendor/three/LICENSE)。

当前模拟器版本v0.6：神秘背景音乐与环境声独立循环，四种野兽吞噬音效；声音设置可分别控制音乐、音效与配音。首次点击后播放声音。

当前模拟器版本v0.6.1：首次进入先选择开始或继续；新手从第1日空监狱开始，巡监开启第一间牢房。预设练习和原创挑战会明确说明初始囚犯。取消开局保留原存档；旧存档可以继续。

当前模拟器版本v0.6.2：持续培养更多绮彩为基础经营目标，至臻刑具为阶段奖励；显示当前至臻、累计绮彩和剩余经营日。右侧拆分本轮经营、声音与可收起收益辅助，挑战模式在起始页选择。暗银黑铁奖励卡、原创物品图与事件说明保持原操作规则；牢房选择同步标记目的地、牢房与确认；提高背景音乐存在感，保留手动声音偏好。

当前模拟器版本v0.6.3：八句女声播报与新开牢门对应野兽声；原创挑战v2含公开合约变体、前两单成功后刑具三选一和每次1券单次刷新。绮彩按身份进入右侧收容框，多个头像与真实当前集合同步。旧挑战v1继续原规则重放。

当前模拟器版本v0.6.4：可编辑Three.js监狱模型接入，16房、悬空平台、铁链、深井与火盆统一倾斜镜头；开门和吞噬沿用真实状态，地板投影决定点击范围。原玩法、存档和声音保持兼容。

当前模拟器版本v0.6.5：四首背景音乐进入随机循环，可随机换曲或指定；左侧经营记录显示本局已发生的操作、奖励与事件，吞噬目标标记更清晰。声音设置采用游戏内面板，女声与野兽音效保持，原玩法规则与存档继续兼容。

当前模拟器版本v0.6.6：两侧边缘按钮独立收起经营记录和右侧栏；问号设置的「沉浸操作」一次收起两栏，场景占满可用区域，布局偏好保留。效果与记录只显示自定义说明浮层，时间轴用单色动物剪影；棋盘头像、养成规则和存档保持兼容。
